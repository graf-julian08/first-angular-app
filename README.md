# First Angular Web Application

## Übersicht
Das Projekt **first-angular-app** ist eine Single-Page-Webanwendung auf Basis des Angular-Frameworks zur Demonstration von Komponenten-Architekturen, Data-Binding und Angular-Services.

## Projektstruktur & Architektur
- `src/app/`: Angular-Komponenten, Vorlagen und Stylesheets.
- `angular.json`: Workspace-Konfiguration der Angular CLI.
- `tsconfig.json`: TypeScript-Compiler-Einstellungen.

## Hauptfunktionalitäten
- **Komponenten-Architektur**: Aufteilung der Benutzeroberfläche in wiederverwendbare Bausteine.
- **Zustandsverwaltung**: Nutzung von Angular Services zur Datenbereitstellung.
- **TypeScript Integration**: Typensichere Entwicklung im gesamten Framework.

## Ausführung & Nutzung
Der Angular-Entwicklungsserver wird über `npm start` oder `ng serve` gestartet.
